# Electronic Product Table
About the Project

This project displays an Electronic Product Table created using HTML and CSS. It shows product names, quantities, per-unit prices, amounts, and the total amount.

# Technologies Used
HTML5
CSS3
# Features
Displays 10 electronic products
Shows product names and quantities
Includes per-unit prices and total amounts
Blue table headings with white text
Hover effect on table rows
Collapsed table borders
Total amount displayed at the bottom
Products Included

How to Run
Save the code as TABLE.html.
Open the file in any web browser.
View the electronic product table and its details.
